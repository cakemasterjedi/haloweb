Install the emblem firmware

For the Waveshare ESP32-S3 2.8C round display. Nothing to download or install on your computer: this page does it from the browser.

1. Install

  1. Use Chrome or Edge on a computer (Windows, Mac, Linux or Chromebook). Phones, Safari and Firefox can't do this.
  2. Plug the display into the computer with a USB-C data cable. Some cables only charge; if nothing shows up, try another one.
  3. Click Install, pick the port that appeared (it usually has USB or CH343 in the name), click Connect, then Install.
  4. Wait for Installation complete (about a minute). The display restarts with the emblem on it.
This browser can't install firmware. Open this page in Chrome or Edge on a computer. Open this page from its https address, not as a file on your computer.

Firmware build __VERSION__

No port in the list? Windows usually installs the USB driver by itself after a minute. If it doesn't, install the CH343 driver from wch-ic.com and try again. Still nothing: unplug, hold the board's BOOT button, plug back in, let go, and click Install.

2. Control it from your phone

  1. Power the display. It makes a Wi-Fi network called BMW-Emblem, password emblem123.
  2. Join it on your phone. The control page opens by itself; if not, open http://192.168.4.1. On Android, choose Stay connected when it says there's no internet.
  3. Pick a design, brightness and power settings. Settings are saved on the display.
  4. Car battery reading: on the Power tab set the voltage source to Car battery (INA219), turn on battery protection and calibrate it with a multimeter reading.

3. Updating later

Once it's in the car you don't need the USB port. Download the update file, join BMW-Emblem, and install it from the control page under Settings → Firmware.
